# Windows Data-Acquisition Software

*What's New*

With WINview ($99), you can acquire, display, and store data from data-acquisition boards. The program can display collected data in engineering units, including volts, degrees, and microstrain; display inputs in one graph or in separate graphs per channel; provide selectable x-axis settings for samples, seconds, minutes, hours, or days; and stream to disk at up to 333 kHz.
