# Physical Property Database for Chemistry

*What's New*

Now you can perform combination searches on a chemical's name, synonym, formula, structure, or CAS number to access compound information. Renaissance Data Pro ($950) for Windows combines search options and the AIChE DIPPR Pure Component Physical Property Database with the ability to cut and paste information into word processors and spreadsheets. You can also search for compounds with specific properties.
