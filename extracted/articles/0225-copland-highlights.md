# Copland Highlights

*Special Report*

Apple will release the OS in stages. Open Transport for networking is already out. A mid-1997 release will provide:

Native PowerPC multithreaded Finder.

Java virtual machine.

Advanced user-interface elements.

OS parts for 680x0-based Macs.

The Patch Manager's limited support for 680x0-trap patching.

Complete memory protection for the kernel, drivers, and server tasks. The kernel provides preemptive scheduling with priority levels.

Limited memory protection and cooperative task scheduling for existing applications that require user interface (necessary for compatibility).

Support for multiple processors. QuickTime 2.5, QuickDraw 3D, etc., already multiprocessor-ready.
