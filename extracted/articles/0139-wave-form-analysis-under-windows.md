# Wave-Form Analysis Under Windows

*International What's New*

The latest version of Famos, a wave-form-analysis package for Windows platforms, allows you to display up to 150 wave forms in one window and resample wave forms at different speeds. With Famos, you can group several wave forms and perform analysis on selected wave forms simultaneously. You can also drag and drop coordinates and axes between windows, which makes the editing process much easier.
