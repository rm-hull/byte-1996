# PC Card with Ethernet/Fax/Modem Functions

*International What's New*

Accton's EN2218 is a PC Card-compatible board that includes Ethernet, fax, and modem functions. When you plug the unit into a notebook's Type II PC Card slot, it provides 10Base-T functionality, a 14.4-/28.8-Kbps data/fax modem, or simultaneous LAN and modem operations. The card also includes software that automatically configures the card and installs network software drivers. Just plug it in for automated installation onto Novell networks.
