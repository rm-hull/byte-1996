# Fast Infrared-to-LAN Access

*International What's New*

Tekram's IRNet IR-610 is a wireless infrared-to-LAN access adapter that links a LAN to an infrared-based portable PC. All you have to do is set your infrared-equipped notebook PC in front of the IR-610's transceiver adapter and log on to your network directly. It allows you to access network databases, check e-mail, connect to the Internet, print documents, and transfer files. Compliant with the IRDA standard, the IRNet IR-610 connects to a standard Ethernet network and supports 115.2-Kbps, 1.52-Mbps, and 4-Mbps infrared protocols. The IR-610 runs under Windows 95 and supports Novell NetWare and Microsoft's LAN Manager and Windows NT.
