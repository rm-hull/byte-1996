# CTI Applications Development Tools

*International What's New*

Rhetorex Europe is offering a new starter version of its Visual Telephony kit for Windows 95 and NT. The kit's development tools support up to 30 ISDN lines and let users develop multichannel voice-processing applications, such as voice mail, automated attendants, interactive voice response, audiotex, and predictive dialers.

Price: Starts at 599 Pounds UK.
