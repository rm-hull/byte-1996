# Integrate Vector Graphics into HTML

*International What's New*

With MetaWeb, you can integrate scalable CGM vector graphics into any HTML document, thereby linking certain elements of the graphics with other documents. The software package, for Windows 3.x, comprises an authoring tool, a helper application, a Netscape plug-in for Windows Web browsers, and a CGM viewer. MetaWeb also imports and exports WMF files.
