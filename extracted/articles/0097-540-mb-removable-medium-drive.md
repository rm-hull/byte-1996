# 540-MB Removable-Medium Drive

*What's New*

The APS M540 uses 3-1/2-inch 540-MB data cartridges, which format to 515 MB in a Mac OS environment. The drive supports sustained data transfer rates of as high as 3.04 MBps with an average seek time of 10.7 ms and an average access time of 27 ms. The 4500-rpm APS M540 uses a 512-KB cache buffer and PRML technology for optimized data transfer rates.
