# Process Monitoring and Sequence Control

*International What's New*

Windmill is a suite of data acquisition and control software. It can log data to disk at up to 200 samples per second. The program runs under all Windows flavors; handles over 100 input and output channels; and integrates Ethernet, GPIB, Modbus, RS-232, and RS-485 devices. Applications include process mimicking, logging, charting, alarm monitoring, and sequence control.
