# Who's Where 2.0

*What's New*

A computerized in/out board and messaging package for LANs and WANs, Who's Where 2.0 for Windows offers automated status log-in upon start-up, automated status log-out upon shutdown, group messaging, TCP/IP support, reporting capabilities, and integration with e-mail. Stand-alone version, from $50; 10-user license, $395; 25-user license, $835; 50-user license, $1295.
