# Monitor Internet Usage

*What's New*

Companies can manage and report their Internet, intranet, and on-line usage with Sequel Net Access Manager 1.0 (one to 49 users, US$89 per user). You can have the program report at the group level; activate or deactivate logging or monitoring functions; and grant or deny site access. The program enables you to monitor Internet activity based on protocols such as HTTP, NTTP, FTP, and SMTP; internal Web servers; and centrally accessed on-line services.
