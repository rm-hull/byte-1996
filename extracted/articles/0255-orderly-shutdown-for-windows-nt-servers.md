# Orderly Shutdown for Windows NT Servers

*What's New*

Designed for unattended remote Windows NT servers, Sentry ShutDown Remote Power Manager provides a multilevel-password interface for power management of mission-critical NT servers and worksta-tions. The product comes in two versions, supporting out-of-band modem and RS-232 communications ($669.95 and $719.95, respectively); an optional model supports an in-band telnet TCP/IP session.
